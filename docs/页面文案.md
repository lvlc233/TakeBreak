# 歇一会儿页面文案 Android 1.0

这里列出 Android 1.0 各页面及弹窗的实际显示文字。方括号表示运行时替换的数字或手机品牌。

## 共用页头

- TAKE A BREATH
- 歇一会儿
- 页签：计时 / 设置 / 准备

## 计时页

- 圆形主控状态：启动 / 正在计时 / 已暂停 / 休息一下下
- 运行或暂停时：已使用 [秒数] 秒 / [提醒间隔] 分钟
- 圆形主控操作提示：轻点开始 / 轻点暂停 / 轻点继续 / 继续按住…
- 圆形主控下方：长按结束并清零
- 这是一个用来防止你刷刷手机的软件，献给无法停下来的我们。

圆形主控的触摸反馈：按下缩小，松开回弹；点按有水波纹和轻震动。外围进度环随使用时间推进，运行时缓慢呼吸，暂停时转为暖色。计时或暂停时，长按约 1.6 秒会出现逐渐填满的暖色圆环，短震从慢到快；完成时恢复最初版本的较长震动并结束清零，不播放自制钟声。提前松手按普通轻点处理；手指移出按钮则取消。未开始计时时长按不会触发结束反馈。

## 设置页

- 设定节奏
- 多久提醒一次
- 分钟 · 累计亮屏时间（1–240 分钟）
- 休息多久
- 分钟 · 到时自动解锁（1–120 分钟）
- 提前解锁写多少字
- 字 · 可用输入法语音转文字（1–200 字）
- 运行中会锁定时长设置；停止提醒后可调整。
- 休息时暂停视频
- 支持 Bilibili、YouTube、抖音、快手；不会向网易云音乐等音乐应用发送暂停。
- 开启视频暂停
- 视频控制需要单独授权。安卓会授予读取所有通知的能力；本应用只查询媒体播放会话，不读取或保存通知内容。到「准备」页查看权限。
- 页面底部按钮：开启休息提醒 / 暂停计时 / 继续计时

## 准备页

- 运行准备
- 总览：正在检查… / [已完成数] / [总项数] 项已完成 / 已就绪，可以开始
- 初始说明：点下方按钮，按顺序打开需要授权的系统页面。
- 系统权限
- 已开启的项目会自动跳过；返回应用后继续检查下一项。

| 权限名称 | 说明 |
| --- | --- |
| 悬浮窗 | 让休息页盖住视频应用 |
| 使用情况访问 | 统计亮屏使用时间 |
| 精确提醒 | 按时唤醒休息提醒 |
| 电池优化 | 减少后台计时被暂停 |
| 通知 | 显示正在计时的通知 |
| 视频控制 | 仅在开启视频暂停时需要 |

- 权限状态：正在检查… / ✓ 已开启 / 待开启 · 点击前往 / 本机无需设置 / 未启用视频暂停
- [品牌] 后台设置
- 这项由手机厂商管理。建议按上方路径检查，系统权限完成后即可开始计时。
- 按钮：打开本机应用设置
- 页面底部按钮：逐项配置运行准备 / 准备已完成 · 返回计时

### 自动选择的品牌路径

应用根据手机的厂商标识自动选择下列一条路径显示。

- OPPO：应用详情 → 耗电管理 → 开启「允许完全后台行为」和「允许应用自启动」
- realme：应用详情 → 电池/耗电管理 → 允许后台运行和自启动
- 一加：应用详情 → 电池 → 允许后台活动；检查自启动设置
- 小米 / Redmi / POCO：应用详情 → 省电策略 → 无限制；并在权限设置中允许后台自启动
- vivo / iQOO：设置 → 电池 → 后台耗电管理 → 允许后台耗电；并开启自启动
- 三星：设置 → 电池 → 后台使用限制 → 将本应用移出休眠列表，加入永不休眠的应用
- 华为 / 荣耀：设置 → 应用和服务 → 应用启动管理 → 手动管理 → 允许自启动、后台活动
- 其他品牌：应用详情 → 电池/后台使用 → 允许后台运行或选择「不受限制」

## 休息弹窗

- 休息时间
- 你现在觉得怎么样？
- 这段时间里感觉还不错吗？来，深呼吸。这回不知道你是在娱乐，又或者在学习、工作，也不知道是否疲倦或是兴奋，但至少在这段时间里，应该属于你自己。
- 还有 [分钟] 分钟自动解锁
- 如果现在要做事情的话，让我们稍微复盘一下吧？你觉得如何呢？说说你现在的想法吧。
- 输入框占位：我现在……
- [已输入字数] / [所需字数] 字
- 按钮：我准备好了

输入框会向手机输入法提示使用简体中文。输入法是否自动切换由具体输入法决定；OPPO K10 真机测试时切换到了中文输入状态。
